## 当前笔记的范围

相同观测归约、有限源单终端 block 信息瓶颈，以及公平 BSC 上 Mrs. Gerber 引理的所需特例，是标准结果的自包含重证。

对 $(p,q)=(1/4,1/8)$ 和固定参考 $P_V=(3,1,1,3)/8$，集中收缩系数仍然是

$$\eta_{\rm MI}(P_V,K)=\eta_{\rm KL}(P_V,K)=\frac13.$$

这个 $1/3$ 是集中编码的固定参考系数。集中编码没有局部消息的条件独立结构。

对同一源上的一切有限块长、无交互局部固定长度码，笔记证明

$$I(X^m;J_1,J_2)\le\frac14\bigl[H(J_1)+H(J_2)\bigr]\le\frac14\log(M_1M_2),$$

因而 $L=C_{\rm fin}=1/4<1/3$。单终端 BSC 码族的效率趋于 $1/4$，与这个上确界匹配。相应操作外界是

$$\Delta\le\min\left\{\frac{R_1+R_2}{4},\,I(X;V)\right\}.$$

这是有限范围的非形式化数学审读，不是新颖性认证、形式化认证或完整区域。全部正率上的 $G(r)=r/4$、$\Psi_{1/10}$ 张量化都没有证明。2026 年相关文献的全文仍未审核，见 [参考文献](../references.md)。
