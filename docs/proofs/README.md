## 校准与收缩笔记的范围

相同观测归约、有限源单终端 block 信息瓶颈，以及公平 BSC 上 Mrs. Gerber 引理的所需特例，是标准结果的自包含重证。

对 $(p,q)=(1/4,1/8)$ 和固定参考 $P_V=(3,1,1,3)/8$，笔记证明集中收缩系数

$$\eta_{\rm MI}(P_V,K)=\eta_{\rm KL}(P_V,K)=\frac13.$$

由此得到原分布式模型的全块外界

$$\Delta\le\min\left\{\frac{R_1+R_2}{3},\frac34\bigl[1-h_2(1/6)\bigr]\right\}.$$

这是有效外界。它不是分布式可达性，不是紧界，也不是新颖性或形式化认证。

操作事实 $L\in[1/4,1/3]$ 和 $L=C_{\rm fin}$ 已在该笔记中证明。统一严格间隙 $L<1/3$ 没有证明。完整分布式区域和 $\Psi_{1/10}$ 的二字母等式也没有在该笔记中证明；这些条目的文献状态没有全部核对。2026 年相关文献的全文仍未审核，见 [参考文献](../references.md)。
