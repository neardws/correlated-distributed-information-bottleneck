# 研究路线

路线描述的是证明工作的顺序。本次仓库初始化只把模型和问题写清楚，不执行这些步骤，也不启动后续计算。

## 本次初始化的边界

已经写下的内容是：操作模型、文献结论及其假设、候选界台账、二元族的初等概率、一个未证明的二字母等式，以及三篇文献的题录。

没有做的内容是：后续文献的系统检索、条件独立定理的证明复写、基数证明、对称性归约、任何数值优化、神经网络训练，以及张量化的证明或反例。

## 后续顺序

1. **模型与文献核对。** 统一记号，在全部假设下复写条件独立定理，并阅读证明。检索对象包括相关观测的 CEO、远程对数损失、多终端信息瓶颈，以及同一操作模型下的张量化文献。同时核对整块对数损失、逐坐标对数损失、相关度约束、随机性和时间共享是否在各来源中一致。若找到覆盖所选模型的定理，就停止把测试点当作未探索对象。
2. **基线。** 收回 $q=p^2$、重复观测、零速率和无限速率这些极限。消息码率与辅助变量上的信息惩罚继续分开。
3. **界的推导。** 为 [内界与外界台账](bound-ledger.md) 中的候选内界写出完整可实现性，并为每个外界记录所用假设。一条外界若用到条件独立，就从相关模型的台账里删除。
4. **单字母认证的前提。** 建立适用的辅助变量基数上界和对称性归约。源分布的对称性，以及对称参数化上的数值成功，都不能单独证明每个最优解都可以选成对称的。
5. **小块比较。** 只有前四步完成之后，才比较明确写出的一字母族和二字母族，并标明限制。初始计划不包含大规模计算。
6. **证明或反例。** 一条路径是保留条件相关项 $I(U_1;U_2\mid X)$ 的张量化不等式。另一条路径是构造两字母候选，并为一个清楚陈述的单字母上界给出证明。能用区间或可检验的解析不等式时，优先使用它们。
7. **停止与改写。** 若发现匹配的已有定理，就不再把所选点写成未探索。若基数或全局最优证书仍然缺失，就只报告受限制族的证据。失败的算法、浮点结果和有限 UNSAT 证书都不是一般编码定理。

## 可以称为结果的交付物

以后可以称为结果的对象只有这些：一份把假设写全的模型笔记，一份核对过的界台账，一个辅助变量归约的证明，或者一个针对明确受限命题的、带证明的反例。

不预先承诺定理、改进、实验或出版。

## 停止条件在文档中的对应位置

| 若出现 | 要改的文档 |
| --- | --- |
| 已有定理覆盖相关二元族或该有理点 | [已知结果](known-results.md)、[未证明的问题](open-questions.md) 的状态 |
| 候选内界的可实现性写完 | [内界与外界台账](bound-ledger.md) 中 I0 的状态 |
| 基数上界被证明或被正确引用 | 台账和未证明问题中关于穷尽枚举的句子 |
| 二字母等式被证明或被反例否定 | [未证明的问题](open-questions.md)，并保持解释限度 |
| 整块损失与逐坐标损失的关系被证明 | [编码模型](coding-model.md) 与已知结果中的未闭合读法 |
